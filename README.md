# FINA website

A responsive, multilingual brand presentation website for FINA.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — RO / RU / EN language switcher

## Before publishing
1. Replace the empty `mailto:` link in `index.html` with your real contact email.
2. Add real product photographs if available (the current hero and feature visuals are CSS illustrations).
3. Update product details to match the exact materials and construction of your inhaler.
4. Add your Instagram, Facebook and WhatsApp links when ready.

## Deploy on Render
Create a **Static Site**, connect this GitHub repository, set the branch to `main`, and leave the Build Command empty. Set the Publish Directory to `.` (a single dot).
